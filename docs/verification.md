# 迁移验证记录

验证日期：2026-10-13。基准：父目录 `ai_studio_code_v2.html`。

后续规则修正：查看提示时，对当前章节每个分数取 `min(当前值, 0)`，清空正分并保留负分。单元及浏览器测试覆盖混合正负分、连续查看、当前题不奖励，以及下一题恢复正常加分。视觉对照仅将旧页的提示文案同步为这次明确修改的文案，旧版计分代码及快照文件不变；新计分规则按新需求独立验收。

后续多音字修正：旧版与迁移版都保留了词组查音和补丁表，但 `Intl.Segmenter` 会将“沉默了一会儿”拆出“了一”，将“提高了一点”拆出单独的“了”，丢失读音上下文。现在先按连续中文推导拼音，再映射至界面分词，全拼和缩写共享读音；移除将非首字 `liao` 一律改为 `le` 的规则。新增 7 项单元测试及 2 项浏览器测试，以明确的正确读音验收截图原句、“了解、了结、没完没了”、缩写和中英混排，并实际导入、输入 `le`、检查对应汉字变绿。旧版一致性测试只能证明抽样行为一致，不能证明旧版的读音正确，因此保留原对照之外增加这些独立回归预期。

## 覆盖的行为

- 初始进度零点、−100%/100% 边界、0.25 超额奖励、均方缺口折扣、超额不能掩盖未达标项。
- 同一部分反复扣分至 −6；按稳定 ID 归属分数；提示清空当前章节所有正分、保留负分和其他章节分数。
- 听音题袋和干扰项约束；三类题型均检验普通试听不扣分、整组完成才奖励、提示组不奖励。
- A–Z 三轮自动推进，逐键成功/错误音效、每轮完成和弦，错误只重置当前轮，第三轮后手动加练。
- 正式填空前两位不判错不发音，退格修改，第三位后统一判定，内联提示、重复扣分、正常奖励。
- 33 个打字章节全部通过实际 DOM 键盘事件完成一轮；刻意让事件的物理大小写、IME 字段与内部状态冲突，验证系统只按内部模式和 `code` 判定。
- 大小写、Shift 按下/松开、输入法切换、ü、标点、拼音上下文、缩写、逐字变绿、双行与多行任务。
- 普通题错误/超时重回第 1 题；前两章完整达标后进入下一章；最终章完成后提高难度回到课程开头。
- UTF-8 与 GBK 词库导入、章节跳转、音频本地预加载、桌面及窄屏布局。

## 比较方法与边界

对照测试在真实 Chromium 中访问生产构建与旧版快照，使用相同随机种子；旧版 CDN 请求在测试边界替换为同版本的本地 pinyin-pro。每章比较内容与实际生成的键盘任务，另做截图像素比对。

视觉比较关闭两边的动画和过渡，并遮住持续变化的底部倒计时条，以比较相同静止状态。动画样式本身由 CSS 完整规则对照覆盖；计时/转场和音效调度由交互测试覆盖。截图测试的容差上限为 0.1%，本次 35 章实际差异均为 0。

本次验证环境为 Windows、Node 22.16.0、npm 10.9.2、Vite 8.3.4、Playwright 1.64.0 和本机 Chromium。没有宣称已完成 Safari、Firefox 或各种物理音频设备的验收。音效验证检查真实 Web Audio 调用，保留原始录音，不替换产品判定函数来模拟通过。
